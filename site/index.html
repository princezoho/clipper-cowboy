The problem

Generation is fast. Memory is not.

Your best shot should not depend on remembering a filename.

The take exists. Somewhere. In a montage, an export folder, a renamed drive, or a prompt batch from three weeks ago. Clipper Cowboy turns that mess into coverage you can see, search, and send to the cut.

01“I know I made that shot.”Search the people, place, object, action, or tag instead of the filename.

02“Which version was the good one?”Keep the exact in and out range—not another mystery duplicate.

03“Where did that file move?”Roundup keeps an identity trail as media moves through your machine.

The workflow

From generation pile to edit-ready package.

01 See the coverage

Review the batch as a body of work.

Pool gathers source generations into one visual surface. See what has already produced selects, what still needs attention, and where the gaps are.

02 Save the take

Keep the moment—not another whole file.

Set the exact in and out points. Name the clip. Tag the character, scene, object, and action while the shot is still fresh in your head.

03 Recall the world

Ask for the shot the way an editor thinks.

Find Ada at the signal tower. Find the insert with the red key. Find every clean reaction tagged “suspicious.” Start the edit from known-good coverage instead of scrubbing raw generations again.

Your catalog lives beside the work. Optional AI can help describe it, but your footage stays local unless you explicitly choose an external pass.

Before you clone it

The straight answers.

Does my footage leave my machine?

Core review, clipping, cataloging, Roundup, and packaging are local. OpenAI features are optional and require a configured key plus an explicit action before sampled frames are sent.

Is this a hosted service?

No. It is a local-first beta you run on your own machine. There is no account, subscription, remote media library, or cloud lock-in.

Can it work with Stem Studio and Premiere?

Yes. Universal Clipper can call an explicitly configured official Stem Studio MCP, and the included Premiere UXP panel imports validated packages into predictable bins.

Can an AI agent use it?

Yes. The standalone MCP exposes a narrow, ID-based tool surface for setup checks, source and clip search, metadata updates, exports, and explicitly confirmed analysis.
