## Stem Studio

Clipper Cowboy interoperates with the separately installed official Stem Studio
MCP server:
<https://github.com/wassermanproductions/stem-studio>.

Clipper Cowboy does not include, modify, or redistribute Stem Studio worker
source or model weights. Stem Studio and its models retain their own upstream
copyright and license terms. Max is never selected automatically because its
additional model has separate upstream licensing.

## Audio models and libraries

Clipper Cowboy does not install or download audio models. Complete setup and
license review in Stem Studio itself before asking Universal Clipper to run the
official MCP connector.
